# Dragonkin Plus 1.0.0

Multipliers, cheats and quality-of-life for **Dragonkin: The Banished**, in five tabs of
the F7 panel.

**Requires the Dragonkin Mod Loader** (install it first).

## Features
* **Multipliers:** XP, wyrmling XP, **city XP**, gold, equipment drops and quality, loot
  quality, materials, eggs, skill fragments, hatch chance, pickup range, damage, critical
  damage, max health, healing, cooldowns, skill cost, resource gain, movement speed,
  attack speed, dodge distance.
* **Cheats:** god mode, unlimited mana / potions / dodge, full ultimate, game speed,
  unlock all waypoints, open the teleport map anywhere, attribute points.
* **Convenience:** camera distance, enemy health and damage, extra speed in the city,
  "I'm stuck!", three saved positions per map, **bigger bag and chests**, sell
  junk-marked items anywhere, crafting gold cost, auto potion, hide the level-up
  notification, the game's hidden **DPS meter**.
* **Console:** developer switches left in the game (always show enemy health bars, ...).
* **Status:** connection state and every player attribute.
* Every change is undone when you switch the mod off.

## Install
1. Install the **Dragonkin Mod Loader**.
2. Extract this archive into the game folder `Dragonkin - The Banished` (so that
   `DragonkinTheBanished\Binaries\Win64\Mods\DragonkinPlus\DragonkinPlus.dll` exists).
3. In game press **F7** → **Mods** → tick **Dragonkin Plus** and **Allow native code**.
   Its five tabs appear immediately.

## Uninstall
Switch it off in the Mods tab, then delete `Binaries\Win64\Mods\DragonkinPlus`.
**If you enlarged the bag or chests, empty the extra slots first** — after uninstalling,
items beyond the game's normal size are lost.

## Notes
* Use it offline / solo. Online cities and co-op are checked by the server.
* The bag size applies at the next area load, chest size at the next game start.
* Settings: `Mods\DragonkinPlus\DragonkinPlus.ini`. Log: `DragonkinPlus.log`.
* Includes Dear ImGui (MIT), see `THIRD_PARTY_NOTICES.txt`.
